데이터 사이언스 — 질문에서 판단까지

2026년 9월 17일4 min read

“매출을 분석해 주세요”라는 요청만으로는 필요한 작업을 정할 수 없습니다. 비교할 기간과 취소 주문의 처리 기준, 결과로 내릴 결정을 먼저 정해야 합니다.

개념 지도

질문 정의 → 수집 → 행과 열의 의미 확인 → 품질 진단 → 변형·집계 → 탐색과 가설 확인 → 근거와 한계 전달

프로그램은 반복을 처리하고, 통계는 불확실성을 해석하며, 도메인 지식은 취소·환불 같은 현장의 의미를 정합니다.

질문접근결과의 예
무슨 일이 있었나?기술적 분석지난달 매출 합계와 변화율
왜 달라졌나?진단적 분석상품·고객군별 차이와 원인 후보
앞으로 어떻게 될까?예측적 분석판매량 추정과 오차 범위
무엇을 해야 할까?처방적 분석비용·재고·공급 시간을 반영한 주문량

판매량 예측만으로 재고 주문량이 정해지지는 않습니다. 현재 재고와 품절 손실 같은 제약을 함께 봐야 합니다. 모든 질문에 머신러닝이 필요한 것도 아닙니다. 합계를 묻는 질문에는 집계가 먼저입니다.

출처: 데이터 사이언스 오버뷰 강의 자료 10–22, 59–63쪽을 바탕으로 재구성. 예시는 가상 데이터입니다. 자료 구성 기준 · 예정 학습 흐름

퀴즈: 매출 분석을 시작하기 전에 무엇을 정할까?

가상의 요청입니다. “이번 달 매출이 괜찮은지 분석해 주세요.”라는 말을 들었습니다. 곧바로 예측 모델을 만드는 대신 먼저 확인할 세 가지를 적어 보세요.

정답과 이유 보기

예를 들어 비교 기간과 기준(지난달인지 작년 같은 달인지), 매출의 정의(취소·환불 포함 여부), 결과로 내릴 결정(재고를 늘릴지 등)을 확인합니다. “괜찮다”의 판단 기준이 없으면 계산이 정확해도 요청에 답하지 못합니다. 기간별 합계 비교로 충분한 질문이라면 예측 모델이 필요하지 않습니다.

복습을 위해 만든 보충 문제입니다. 실제 학습자의 응답 기록은 아닙니다.
