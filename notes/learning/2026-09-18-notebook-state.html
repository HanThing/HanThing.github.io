코드를 고쳤는데 list 오류가 계속 나는 이유

2026년 9월 18일7 min read

17번 제곱 리스트 문제를 풀던 중 'list' object is not callable 오류가 났다. 이 기록은 화면을 확인한 당시 설명과 사용자의 후속 발언을 구분해 정리했다. 아래 코드는 원문에 제시된 핵심 줄이며 노트북 전체를 복제한 것은 아니다.

질문 제목은 실제 발언의 뜻을 유지해 다듬었다. 의도는 사용자가 직접 밝힌 경우를 제외하면 대화 맥락을 바탕으로 정리한 해석이다.

질문: 17번에서 list object is not callable은 왜 나올까?

상황: 숫자 리스트에 list라는 이름을 붙인 뒤 list(map(...))를 실행했다. 기대한 것은 제곱한 숫자 리스트였지만, 리스트를 호출할 수 없다는 오류가 났다.

의도: 제곱 계산식이 틀렸는지, 오류 메시지의 list가 무엇을 가리키는지 확인하려 했다.

핵심 답변: list = [1, 2, 3, 4, 5]를 실행해 내장 list 이름을 가렸다. 이후 list(...)는 리스트 생성 기능이 아니라 그 숫자 리스트를 호출하려 하므로 실패한다.

설명에서는 숫자 묶음의 이름을 nums로 바꾸고, 이미 만든 list 바인딩은 별도로 없애야 한다고 안내했다. 내장 클래스가 파이썬에서 삭제된 것은 아니다.

질문: 이름을 nums로 고쳤는데 왜 같은 오류가 남을까?

상황: 사용자가 “지금은 또 왜 안 되지?”라고 물었다. 당시 화면 확인에서는 편집한 이름은 올바르게 바뀌어 있었고, 앞서 실행한 list 이름이 남은 상태로 설명됐다.

의도: 코드의 글자를 수정하면 실행 환경도 함께 이전 상태를 잊을 것이라는 기대와 실제 동작의 차이를 이해하려 했다. 이 기대는 질문 흐름에서 추론한 것이다.

핵심 답변: 셀의 텍스트와 실행 중인 파이썬의 이름 공간은 다르다. nums = ...를 실행하면 nums가 생기지만 예전 list가 자동 삭제되지는 않는다. 노트북 셀들은 같은 실행 상태를 공유한다.

질문: del list로 해결됐는데, 정확히 무엇을 지운 걸까?

상황: 사용자는 del list 뒤 문제가 해결됐다고 직접 말하며 “이런 현상이 왜 발생하는지 정확히 이해하고 가고 싶다”고 요청했다.

의도: 일회성 해결 명령만 기억하지 않고, 이름과 객체·내장 기능의 관계를 이해하려는 요청이었다.

핵심 답변: 여기서 del list는 사용자가 만든 list라는 이름 연결을 제거했다. 코드 셀이나 파일을 지우는 것이 아니다. 그러면 이름을 찾을 때 내장 list를 다시 사용할 수 있다.

이 대화에서는 사용자가 해결됐다고 보고한 사실이 있다. 다만 이 문서의 예상 출력 [1, 4, 9, 16, 25]를 당시 화면에서 별도로 검증한 것과는 구분한다. 더 이상 사용자 정의 list 이름이 없는 상태에서 del list를 반복하면 NameError가 날 수 있으므로 습관적으로 모든 셀에 넣는 명령이 아니다.

질문: 홀수 합을 for 없이 구할 수 있을까? 내 for 코드는 문법이 틀렸을까?

상황: 16번은 1부터 100까지 홀수의 합을 구하는 문제였다. 사용자는 반복문 없는 방법을 물은 뒤, 작성한 반복문이 왜 틀렸는지 질문했다. 당시 설명에 따르면 이전 오류 결과에는 초기값 없이 sum += num을 실행한 흔적이 있었고, 화면의 수정 코드에는 sum = 0이 추가돼 있었다.

의도: 반복 방법의 선택과 실제 오류 원인을 구분하려 했다. “문법이 틀렸다”는 질문을 실행 상태와 자료형 문제로 바로잡는 과정이었다.

핵심 답변: 반복문을 직접 쓰지 않아도 sum(range(1, 101, 2))로 합을 구할 수 있다. 직접 누적하려면 숫자 초기값이 필요하다. 초기값 없이 내장 sum에 숫자를 더하면 오류가 난다. 수정 전 출력이 남아 있다면 현재 코드와 실행 결과도 구분해야 한다.

당시 제시된 수정 예는 다음과 같다. 사용자의 재실행 성공 기록은 없다.

sum(...) 방식도 내부적으로 값을 소비해 더한다. 소스에 for가 없다는 것과 반복 계산을 하지 않는다는 것은 다르다.

관련 개념: 노트북 실행 상태, 반복 가능한 객체와 이터레이터, lambda와 map 질문.
