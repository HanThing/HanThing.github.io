객체·인스턴스·self는 어떤 대상을 가리킬까?

2026년 9월 18일9 min read

파일 객체 설명에서 “객체”라는 말이 반복됐지만 실체가 선명하지 않아 클래스부터 다시 물었다. 이후 이름과 점수로 학생 세 명을 만들고 각각의 학점을 출력하는 6번 문제의 Student와 self로 연결했다. 핵심은 단어의 사전적 정의보다 지금 코드가 어느 학생의 정보를 다루는지였다.

질문 제목은 실제 발언의 뜻을 유지해 다듬었다. 의도는 사용자가 직접 밝힌 경우를 제외하면 대화 맥락을 바탕으로 정리한 해석이다.

질문: 객체가 도대체 무엇일까? 변수와 다른 것일까?

상황: 클래스 설명을 요청한 뒤에도 객체라는 말이 이해되지 않는다고 했다. 파일 객체, 문자열, 학생 객체가 한 용어로 불리고 있었다.

의도: 추상적인 “데이터와 기능의 묶음” 대신 코드에서 실제로 가리키는 대상을 찾으려 했다.

핵심 답변: score = 85에서 85는 정수 객체이고 score는 그것을 참조하는 이름이다. 학생을 표현하는 객체도 같은 관계로 이름을 붙여 접근한다. 변수를 두 개 만든다고 항상 객체가 두 개 생기지는 않는다.

당시 설명용 사례는 이랬다.

b = [9, 10]으로 바꾸는 것은 기존 객체를 고치는 것과 다르다. 그 이름을 다른 객체에 연결하는 것이다.

질문: 내가 만든 클래스의 객체만 인스턴스라고 부르는 걸까?

상황: 사용자는 객체가 더 큰 개념이고 인스턴스는 직접 정의한 클래스로 만든 객체라고 자신의 이해를 설명했다. student1은 객체 자체보다 주소를 담는 이름 같다는 생각도 말했다.

의도: 객체·인스턴스·변수를 서로 다른 단계로 분류하려 했다.

핵심 답변: 객체는 구체적인 대상, 인스턴스는 그 대상이 특정 클래스에 속한다는 관계를 강조하는 말이다. 85도 int의 인스턴스다. 사용자 정의 클래스만 해당하는 것은 아니다. 변수는 주소를 직접 조작하는 포인터라기보다 객체를 참조하는 이름으로 이해한다.

당시 자기설명에서 맞는 부분과 이 구분을 고칠 부분을 나눠 설명했다. 처음부터 용어를 모두 이해했던 것으로 정리하지 않는다.

질문: 일반 값도 타입의 인스턴스라면 int 같은 타입도 클래스일까?

상황: 숫자도 인스턴스라는 설명 뒤, 그렇다면 타입도 클래스인지 되물었다. 새로 정의하는 class와 기존의 int, str, list가 연결되지 않은 지점이었다.

의도: 사용자 정의 타입과 파이썬이 제공하는 타입을 하나의 관계로 이해하려 했다.

핵심 답변: 파이썬의 int, str, list도 클래스다. class Student:는 필요한 타입을 직접 정의하는 문법이고, 이미 있는 클래스는 따로 정의하지 않고 사용한다.

type(85)의 결과가 <class 'int'>인 것도 이 관계를 드러낸다. 이 출력은 설명에 제시된 예이며 사용자가 새로 실행한 결과라는 뜻은 아니다.

질문: 클래스의 __init__과 패키지의 init.py는 같은 초기화일까?

상황: 학생 클래스 문제에서 __init__을 보고, 앞서 배운 패키지의 초기화 파일과 비교해 달라고 요청했다.

의도: 비슷한 이름 때문에 같은 실행 장치로 이해해도 되는지 확인하려 했다.

핵심 답변: __init__.py는 일반 패키지를 처음 불러올 때 실행하는 파일이고, __init__ 메서드는 새 인스턴스의 초기 상태를 설정한다. 사용하는 계기와 대상이 다르다.

비교패키지 예학생 클래스 예
대상패키지 준비새 학생의 이름·점수 설정
계기처음 패키지를 importStudent("민수", 85)로 인스턴스 생성
코드 형태__init__.py 파일클래스 안의 def __init__(self, ...)

클래스를 만들기 위해 별도의 __init__.py 파일이 필요한 것은 아니다. 패키지 쪽 실행 주체를 다시 물었던 내용은 import와 초기화 기록에서 이어진다.

질문: 6번 학생 등급 문제에서 self는 왜 필요할까?

상황: 6번 문제의 설명을 요청한 뒤, 작성 중이던 Student 초기화 코드에서 self를 더 깊게 설명해 달라고 했다. 당시 확인된 부분은 self.name = name, self.score = score였다.

의도: 같은 클래스의 메서드가 학생마다 다른 이름·점수를 어떻게 사용하는지 알고 싶었다. 이 구체화는 질문과 당시 코드에 근거한 해석이다.

핵심 답변: 일반 인스턴스 메서드의 self는 이번 호출이 다루는 객체를 받는다. student1.get_grade()를 호출하면 self는 그 학생을 가리킨다. self.score는 그 학생의 점수다.

당시 코드에서 확인한 초기화 부분이다.

설명에서는 민수 85점, 지수 95점인 두 학생을 예로 들었다. 이는 설명용 객체이며 사용자의 실제 인물 정보나 실행 결과가 아니다.

self.name = name의 오른쪽은 전달받은 매개변수 값이고 왼쪽은 객체에 저장할 속성이다. 새 객체를 초기화한 뒤에 student1이라는 이름이 그 객체를 참조하므로, self가 변수 이름 student1을 찾아가는 것은 아니다. self라는 철자는 관례이고, 객체가 전달되는 것은 메서드 호출 방식에 따른다.

사용자는 클래스·객체 관계를 자기 말로 다시 설명했고 교정을 받았다. 그러나 이 대화에서 get_grade를 완성해 재실행하거나 다른 문제에 적용한 결과는 확인하지 않았다.

관련 개념: self와 객체, 파일 객체와 읽은 문자열의 차이.
