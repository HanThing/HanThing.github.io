고정 흐름

import는 파일을 복사하지 않는다

모듈을 찾고 실행해 객체를 만든 뒤, 현재 이름 공간에 이름을 연결한다. 작업 폴더도 바꾸지 않는다. 위키 노트

list = [...]처럼 내장 이름을 변수로 쓰면 이후 list() 호출이 가려진다. 노트북에서는 셀을 고쳐도 이전 이름이 남으므로 del list로 그 이름 연결을 제거하거나 커널을 재시작한 뒤 셀을 순서대로 실행한다.

단계를 선택하세요.
이름 공간

셀 편집과 실행 상태는 다르다

list = [...]를 실행한 뒤 코드를 nums = [...]로 고쳐도 기존 list 이름은 남는다. 위키 노트

내장 list() 사용 가능

f(...)는 호출, nums[0]은 인덱싱, (1 + 2)는 계산 묶음이다. list(map(lambda x: x**2, [1,2,3,4,5]))는 [1,4,9,16,25], sum(range(1,101,2))는 끝값 101을 포함하지 않고 홀수를 더해 2500이다.

소비 상태

이터레이터는 꺼낸 위치를 기억한다

next()로 하나를 꺼낸 뒤 list()로 모으면 남은 값만 들어간다. 다시 쓰려면 이터레이터를 새로 만든다. 위키 노트

남은 값: (A, 1), (B, 2), (C, 3)

정의에서는 모으고, 호출에서는 푼다

*args는 남는 위치 인자를 튜플로, **kwargs는 남는 키워드 인자를 딕셔너리로 모은다. 위키 노트

앞의 식은 매 반복에서 결과를 만든다

matrix = [[1, 2], [3, 4]]
