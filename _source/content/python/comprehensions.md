`[x for row in matrix for x in row]`은 바깥 `row` 반복 뒤 안쪽 `x` 반복 순서로 읽는다. 맨 앞의 `x`는 각 반복에서 결과에 넣을 표현식이다. 여러 동작이 필요하거나 순서가 헷갈리면 같은 구조의 일반 `for`문으로 먼저 펼친다.
