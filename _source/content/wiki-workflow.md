이곳은 원문을 쌓아 두는 보관함이 아니라, 읽은 자료를 설명·예제·질문으로 다시 연결하는 위키입니다. LLM은 자료를 정리하고 연결을 제안하는 작업에 쓰며, 원문에서 확인한 내용과 새로 만든 예시를 구별합니다.

## 자료 하나가 들어오는 순서

1. **출처 확인:** 원문의 범위와 날짜, 기존 정리와의 차이를 확인합니다.
2. **개념 정리:** 한 노트가 하나의 질문에 답하게 나눕니다. 정의뿐 아니라 헷갈리는 반례를 함께 남깁니다.
3. **관계 연결:** 선행 개념과 적용 예제를 문서 링크로 연결합니다. 링크가 검색·그래프·백링크에 반영됩니다.
4. **직접 확인:** 수치나 코드 결과를 점검하고, 조작이 도움이 되는 주제는 학습판에서 비교합니다.
5. **다음 질문:** 아직 확인하지 않은 내용은 [[questions|질문 목록]]으로 이어집니다.

## 현재 들어온 자료

| 자료 | 반영된 형태 | 범위 |
|---|---|---|
| 개인 Notion의 Python 학습 정리 | [[python/index\|개념 노트]]와 [Python 학습판](https://hanthing.github.io/learning/python-lab.html) | 문법과 실행 관계를 복습하는 예제 |
| 데이터 사이언스 오버뷰 강의 자료 | [[data/data-science-overview\|개념 지도]]와 [데이터 학습판](https://hanthing.github.io/learning/data-science-overview.html) | 84쪽 강의 자료의 기초 개념을 재구성 |
| 공개 커리큘럼 시트 | [[bootcamp/roadmap\|부트캠프 학습 지도]] | 2026-09-20 확인한 예정 일정 |

자료를 정리했다는 사실은 학습을 완료했다는 뜻이 아닙니다. 새 자료가 생기거나 설명에 오류가 발견되면 관련 노트와 연결을 함께 고칩니다. 원문 변경을 자동 수집하는 기능은 현재 없습니다.

## 갱신 기록

- **2026-09-20:** Python 학습 정리와 데이터 사이언스 개념을 옮기고, 학습판·부트캠프 일정·질문을 서로 연결했습니다.
